Conditions d'utilisation
Ariane est un appui d'étude : elle organise vos révisions, elle ne remplace ni les cours officiels ni le jury. Les achats sont uniques, sans échéance, sans abonnement — ce qui est payé reste acquis, et rien n'est jamais supprimé à l'expiration d'un droit. Dans cette version, le profil est local à l'appareil : il n'y a pas de compte distant, de synchronisation ni de code envoyé. L'application n'affiche pas de publicité. Vos données vous appartiennent.
Politique de confidentialité
Le prénom, le nom, la faculté, l'email ou le téléphone du profil, la progression et les réglages sont conservés dans le stockage local de cet appareil. Dans cette version, ces coordonnées ne sont pas envoyées à un serveur : Ariane ne crée pas de compte distant, ne vérifie pas l'adresse et n'envoie aucun code. Une sauvegarde que vous exportez peut contenir le profil complet ; gardez ce fichier privé. Aucun traceur publicitaire. Un identifiant aléatoire distinct du profil sert au compteur d'adoption pour régler les paliers de prix, sans nom ni contact. Un avis ou un document que vous choisissez d'envoyer est transmis pour traitement ; n'y ajoutez que ce que vous souhaitez partager. Les documents sont relus avant toute intégration. Une question sur vos données : écrivez-nous via « Ton avis ».

Comment choisir ?

La faculté du profil, le professeur et la matière filtrent les questions disponibles. Le type distingue les cours, les annales et les pièges ; le nombre fixe la longueur de la série. « Tous » est toujours un choix explicite. Si la banque d'une faculté n'est pas présente, ses questions ne sont pas remplacées par celles d'une autre.
